# I18N.md — локалізація (UA/EN)

Три незалежні шари. Плутанина між ними — найчастіше джерело багів з мовами.

## Шар 1: UI storefront (словники)

- Джерело: `apps/storefront/src/i18n/dictionaries.ts`. `uk` — базовий об'єкт,
  `en` типізований під нього (`Dictionary = typeof uk`) — пропущений ключ в en
  ловиться тайпчеком.
- Доступ у компонентах: `const { d, lang, setLang } = useI18n()` (`src/lib/i18n.tsx`).
  SSR завжди рендерить `uk`; збережена мова (`localStorage["nova-lang"]`)
  застосовується після гідрації; провайдер ставить `document.documentElement.lang`.
- Контент 12 інфо-сторінок — окремо в `src/i18n/info.ts` (`infoPagesUk`/`infoPagesEn`),
  підключений у словники як `d.infoPages`.
- **Правило:** жодного видимого рядка хардкодом у JSX. Додаєш текст → додаєш ключ у
  ОБИДВІ мови словника.

## Шар 2: каталог (дані в БД)

- Базові поля product/category — **УКРАЇНСЬКОЮ** (title, subtitle, description,
  metadata.specs/features). Англійська — у `product.metadata.i18n.en`
  (та сама структура полів).
- Локалізація на фронті: `src/lib/catalog-i18n.ts` — `localizeProduct(p, lang)`
  (title/subtitle/description/specs/features) і `localizeTitle(p, lang)` для карток.
  Немає en-значення → graceful-фолбек на базове українське.
- Джерело даних каталогу і як їх безпечно оновлювати — [CATALOG.md](CATALOG.md)
  (коротко: тексти на живій БД синкає ТІЛЬКИ `update-catalog-texts.ts`).

## Шар 3: мова транзакційних листів

- При чекауті/реєстрації storefront пише мову клієнта: `updateCartDetails` →
  `cart.metadata.locale` (переїжджає в order.metadata), реєстрація →
  `customer.metadata.locale`.
- Бекенд резолвить: `resolveEmailLang(metadata.locale)` (`src/lib/email-i18n.ts`) →
  `"uk" | "en"`, дефолт uk.
- Кожен білдер листа має повний STRINGS-словник uk/en усередині файла
  (`order-email.ts`, `customer-email.ts`, `cart-email.ts`); фіксований «хром» шаблону
  (футер, disclaimer, «Кількість/Quantity») — CHROME у `email-template.ts`.
- Кожен лист снапшотиться в ОБОХ мовах (`tests/unit/email-snapshots.spec.ts`).

## Чекліст «додаю новий текст»

| Де текст | Що робити |
|---|---|
| Кнопка/лейбл/повідомлення на сайті | Ключ у `dictionaries.ts` (uk + en) |
| Інфо-сторінка | `src/i18n/info.ts` (обидві мови) |
| Назва/опис товару | Базове поле УКР + `metadata.i18n.en`; на живій БД — через update-catalog-texts (CATALOG.md) |
| Текст листа | STRINGS uk/en у білдері + оновити снапшоти (переглянувши diff!) |
| Текст адмінки | Адмінка одномовна (en/ui-рядки Medusa) — словників не має, пиши англійською як сусідній код |
